# dcsteam

Express by DCS — prototipo de dashboard institucional.

Sitio público: <https://fabriziolm.github.io/dcsteam/>

Prototipo inicial de la aplicación institucional con vistas por cargo.

## Ejecutar localmente

```powershell
npm.cmd install
npm.cmd run dev
```

Abrir `http://localhost:3000` y usar el selector superior para probar las vistas de Propietario, Administrador, Coordinador, Chofer y Auxiliar.
